# Report

This directory is reserved for the project report, covering the methods,
experiments, results, and limitations.

```text
report/
├── README.md
├── figures/
└── sections/
```

The report is planned in LaTeX. Section sources belong in `sections/` and
figures in `figures/`. Generated PDFs and temporary build files belong in
`build/`, which is ignored by Git.

There is no main document or compilation command yet.
